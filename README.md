# ANOMALY-PDA

Справочная интерактивная карта **S.T.A.L.K.E.R. Anomaly** в интерфейсе КПК. Проект предназначен для просмотра заранее подготовленных точек интереса на картах уровней.

**Это не внутриигровая навигация:** приложение не подключается к игре, не отслеживает положение игрока и не строит игровые маршруты.

## Что уже работает

- Экспорт объектов из `all_entities.json` в компактный формат карты.
- Объединение объектов `all.spawn` с дополнительным справочным набором тайников и POI.
- Удаление точных дубликатов по локации, имени и координатам.
- 221 ранее подготовленная точка: 203 treasure, 9 secret, 4 quest, 3 weapon и 2 special на 15 локациях.
- Веб-интерфейс КПК: выбор локации, фильтры категорий, поиск, масштабирование, перемещение, список и карточка объекта.
- Загрузка локального изображения карты и ручная привязка его границ к координатам X/Z.
- Для Юпитера известна координатная область X/Z от −600 до +600.
- GitHub Actions проверяет Python 3.10/3.12 и синтаксис JavaScript.

## Подготовка полного набора карты

Требуется Python 3.10+.

```powershell
python -m pip install -e .
python -m unittest discover -s tests -v
```

Экспорт из локального реестра объектов:

```powershell
python -m anomaly_pda.map_data "D:\Anomaly-PDA\data\processed\all_entities.json" "web\data\map-data.json" --references "data\reference\stashes_and_poi.json"
```

Замени путь к `all_entities.json`, если он находится в другом месте. Сам файл игрового реестра не включён в Git.

## Запуск интерфейса

Из корня репозитория:

```powershell
python -m http.server 8000
```

Открой http://localhost:8000/web/

Если `web/data/map-data.json` ещё не создан, интерфейс автоматически покажет резервный набор из 221 сохранённой точки. Полную карту можно получить двумя способами: заранее экспортировать `all_entities.json` командой выше или нажать в интерфейсе «Загрузить all_entities.json» и выбрать локальный файл. Во втором случае браузер сам обработает реестр, объединит его с 221 справочной точкой и не отправит файл на сервер.

## Текстуры карт

В интерфейсе выбери локацию и нажми «Загрузить изображение карты». Для Юпитера используй чистую текстуру `map_jupiter` без диагностических маркеров и оставь границы X/Z −600…+600.

`map_jupiter_entities_check.png` — контрольное изображение с уже нанесёнными точками; `map_jupiter_grid.png` — проверочная координатная сетка. Они не предназначены как чистая подложка. Для других уровней координатные границы изображения нужно определить отдельно.

## Структура

- `src/anomaly_pda/` — парсеры игровых графов и экспортёр данных карты.
- `data/reference/stashes_and_poi.json` — сохранённые координаты 221 справочной точки.
- `web/` — интерфейс КПК.
- `tests/` — автоматические тесты.
- `.github/workflows/tests.yml` — CI для Python и JavaScript.
