# ANOMALY-PDA

Проект интерактивного КПК (PDA) для **S.T.A.L.K.E.R. Anomaly**.

Цель — построить интерактивную карту Зоны с игровыми графами, точками переходов, маршрутами и навигацией на основе реальных данных игры.

> Сейчас проект находится на этапе исследования и подготовки парсеров игровых форматов. Непроверенные структуры не считаются спецификацией.

## Основные задачи

- [ ] Разбор Game Graph из `db/configs/spawns.db0`.
- [ ] Разбор Level Graph из файлов `level.ai`.
- [ ] Поиск и разбор Cross Table.
- [ ] Связать глобальные вершины Game Graph с локальными вершинами уровней.
- [ ] Извлечь координаты и игровые точки интереса.
- [ ] Построить маршрутизацию между уровнями и внутри уровней.
- [ ] Создать интерактивный интерфейс КПК.

## Подтверждённые данные

Исследование Anomaly подтвердило для текущего набора игровых архивов:

- Game Graph: 5 345 вершин и 13 444 ребра.
- В Game Graph заявлено 764 226 Level Points.
- В графе обнаружено 34 уровня.
- Длины записей рёбер — 6 байт (`<Hf`).
- Записи Level Point — 20 байт (`<fffIf`).
- Суммы счётчиков рёбер и точек согласуются с заголовком Game Graph.

Подробности и ограничения: [docs/FORMAT_RESEARCH.md](docs/FORMAT_RESEARCH.md).

## Принципы разработки

1. Опираемся на реальные файлы Anomaly.
2. Каждое предположение помечаем как гипотезу до проверки.
3. Проверяем размеры структур, диапазоны смещений и ссылки между графами.
4. Не выгружаем многогигабайтные игровые данные без необходимости.
5. Изменения сопровождаем проверками и фиксируем в Git.
