# ANOMALY PDA — веб-карта

Это самостоятельная справочная карта объектов Anomaly. Она не подключается к игре, не отслеживает игрока и не строит игровые маршруты.

## Подготовка данных

Из корня репозитория, где установлен пакет:

```powershell
python -m pip install -e .
python -m anomaly_pda.map_data "D:\Anomaly-PDA\data\processed\all_entities.json" "web\data\map-data.json" --references "data\reference\stashes_and_poi.json"
```

Путь к исходному `all_entities.json` замени на фактический путь к своему файлу. Файл `data/reference/stashes_and_poi.json` уже добавлен в репозиторий: это ранее подготовленная выгрузка из 221 тайника и специальной точки на 15 локациях. Экспортёр объединяет её с `all_entities.json` и удаляет точные дубликаты. Координаты X-Ray: X/Z — плоскость карты, Y — высота.

## Запуск

Из корня репозитория:

```powershell
python -m http.server 8000
```

Открой в браузере: http://localhost:8000/web/

Файл данных должен находиться по адресу `web/data/map-data.json`. Если его ещё нет, интерфейс автоматически откроет резервный набор из 221 ранее сохранённой точки (`data/reference/stashes_and_poi.json`). Поэтому сервер запускается из корня репозитория: так браузер сможет прочитать и папку `web`, и справочные данные из `data/reference`. Не открывай `index.html` напрямую через `file://`: браузер блокирует загрузку JSON через fetch.\n\n## Подложки уровней\n\nВ интерфейсе нажми «Загрузить изображение карты» и выбери изображение нужного уровня. Для Юпитера подготовлена координатная привязка X/Z от −600 до +600: выбери уровень `jupiter`, затем загрузи чистую текстуру `map_jupiter` без нанесённых маркеров. `map_jupiter_entities_check.png` — контрольный снимок с уже нарисованными точками, а `map_jupiter_grid.png` — изображение с координатной сеткой; они нужны для проверки привязки, но не подходят как чистая подложка для финального отображения. Если используешь другое изображение или другой уровень, введи его фактические крайние координаты X и Z в поля привязки. Подложка действует только для выбранного уровня; при переключении локации она не переносится на другую карту.\n\nИзображение выбирается из локального файла браузером и не отправляется на сервер.

## Возможности интерфейса

- выбор одной из локаций, присутствующих в экспорте;
- фильтрация по категориям и поиск по названию/секции;
- масштабирование и перемещение по карте;
- выбор точки кликом и просмотр координат/идентификаторов;
- список объектов выбранной локации.

## Текущие ограничения

На этом этапе отображаются точки на координатной подложке. Географические текстуры/контуры уровней ещё не подключены, поэтому фон пока не является игровой картой местности. Классификация — предварительная по секциям `all.spawn`; содержимое динамических отрядов, NPC и случайных тайников будет уточняться по конфигам и скриптам.
