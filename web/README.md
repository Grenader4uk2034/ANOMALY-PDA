# ANOMALY PDA — веб-карта

Это самостоятельная справочная карта объектов Anomaly. Она не подключается к игре, не отслеживает игрока и не строит игровые маршруты.

## Подготовка данных

Из корня репозитория, где установлен пакет:

```powershell
python -m pip install -e .
python -m anomaly_pda.map_data "D:\Anomaly-PDA\data\processed\all_entities.json" "web\data\map-data.json"
```

Путь к исходному `all_entities.json` замени на фактический путь к своему файлу. Экспортёр сохраняет координаты X-Ray: X/Z — плоскость карты, Y — высота.

## Запуск

Из корня репозитория:

```powershell
python -m http.server 8000 --directory web
```

Открой в браузере: http://localhost:8000

Файл данных должен находиться по адресу `web/data/map-data.json`. Не открывай `index.html` напрямую через `file://`: браузер блокирует загрузку JSON через fetch.

## Возможности интерфейса

- выбор одной из локаций, присутствующих в экспорте;
- фильтрация по категориям и поиск по названию/секции;
- масштабирование и перемещение по карте;
- выбор точки кликом и просмотр координат/идентификаторов;
- список объектов выбранной локации.

## Текущие ограничения

На этом этапе отображаются точки на координатной подложке. Географические текстуры/контуры уровней ещё не подключены, поэтому фон пока не является игровой картой местности. Классификация — предварительная по секциям `all.spawn`; содержимое динамических отрядов, NPC и случайных тайников будет уточняться по конфигам и скриптам.
