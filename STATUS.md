# Статус проекта

**Текущий этап:** базовый веб-интерфейс КПК и конвейер справочных точек реализованы. Параллельно возобновлено исследование глобальной карты Anomaly: оригинальные ресурсы собраны в репозитории, выполнен предварительный аудит координат 24 поверхностных уровней. Следующий практический шаг — проверить размеры DDS и построить диагностическую раскладку.

## Реализовано

- [x] Репозиторий ANOMALY-PDA и базовые Python-парсеры игровых графов.
- [x] Экспортёр `all_entities.json` → GeoJSON-подобный набор объектов с координатами X/Z и высотой Y.
- [x] Классификация основных групп: тайники, аномалии, точки симуляции, мутанты, персонажи, костры, переходы и прочие POI.
- [x] Исправлена приоритетная классификация `m_trader` и `m_lesnik` как NPC; `m_car` выделен в транспорт.
- [x] Добавлен ранее подготовленный справочный набор из 221 точки на 15 локациях: 203 treasure, 9 secret, 4 quest, 3 weapon, 2 special.
- [x] Экспортёр объединяет справочные точки с `all_entities.json` и устраняет точные дубликаты.
- [x] Веб-интерфейс КПК: выбор уровня, категории, поиск, масштабирование, перемещение, список объектов и карточка координат.
- [x] Поддерживается загрузка локального изображения уровня и привязка границ X/Z.
- [x] Полный `all_entities.json` можно импортировать прямо в браузере; файл обрабатывается локально и объединяется с 221 справочной точкой.
- [x] Для Юпитера определена координатная область X/Z −600…+600 по ранее подготовленной сетке.
- [x] Если полный экспорт ещё не создан, веб-интерфейс показывает резервные 221 справочную точку.
- [x] GitHub Actions проверяет Python 3.10 и 3.12, а также синтаксис JavaScript.

## Принципиальные ограничения

- Нет подключения к игровому процессу.
- Нет определения текущего положения игрока.
- Нет маршрутизации или навигации игрока.
- Координатная подложка без текстуры остаётся диагностическим видом, а не готовой игровой картой.
