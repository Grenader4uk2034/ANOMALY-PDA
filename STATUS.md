## Новые подтверждённые сведения

- `level.ai` имеет 56-байтовый заголовок.
- Level Graph v10: 23 байта на вершину; v13: 25 байт.
- `fake_start/level.ai`: 14 569 байт = 56 + 631 × 23.
- `zaton/level.ai`: 42 578 829 байт = 56 + 1 851 251 × 23.
- Cross Table может быть встроена в Game Graph после массива Level Points; отдельный `.gct` для каждой локации не обязателен.
- Cross Table header: 44 байта; ячейка: 6 байт.

## Проверено в текущей среде разработки

- Проверены размеры Python struct layouts: Game Graph header 28, vertex 42, edge 6, point 20; Level Graph header 56.
- Синтетические записи и размеры пакуются в ожидаемые длины.
- Все основные файлы повторно прочитаны из GitHub после записи.

**Важно:** полноценный запуск unit-тестов и прогон новых парсеров по настоящим игровым payload ещё не выполнены в Termux. До этого парсеры не объявляются подтверждёнными на полном наборе игровых данных.
