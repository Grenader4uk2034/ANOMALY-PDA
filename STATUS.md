# Статус проекта

**Этап:** инструменты разбора Game Graph готовы на уровне реализации; далее — проверка на полном игровом payload и исследование Level Graph.

## Выполнено

- [x] Создан отдельный репозиторий ANOMALY-PDA.
- [x] Зафиксированы результаты исследования Game Graph из `db/configs/spawns.db0`.
- [x] Реализован модуль `src/anomaly_pda/game_graph.py`.
- [x] Добавлены структуры заголовка, таблицы уровней, вершин, рёбер и Level Points.
- [x] Добавлены проверки границ, диапазонов и ссылок.
- [x] Добавлены синтетические unit-тесты.
- [x] Добавлены `pyproject.toml` и команда CLI `anomaly-pda-graph`.

## Проверено в текущей среде разработки

- Форматы записей имеют размеры: header 28 байт, vertex 42 байта, edge 6 байт, point 20 байт.
- Синтетические бинарные записи для тестовых сценариев корректно упаковываются и имеют ожидаемые размеры.
- Все добавленные файлы записаны в GitHub и повторно прочитаны после записи.

**Важно:** запуск полного набора unit-тестов и проверка на реальном полном payload ещё не выполнены в среде Termux. Поэтому модуль пока не объявляется проверенным на игровых данных.

## Ограничения и неизвестное

- Полный формат `level.ai` пока не подтверждён.
- Первые поля `level.ai` не трактуются как доказанная версия/счётчик.
- Отсутствие файла с расширением `.gct` в одном архиве не доказывает отсутствие Cross Table.
- `edge.distance` не всегда является прямым евклидовым расстоянием.
