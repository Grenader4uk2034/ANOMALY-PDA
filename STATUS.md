# Статус проекта

**Этап:** базовые парсеры Game Graph и Level Graph, Cross Table reader и первый слой маршрутизации реализованы. Следующий обязательный шаг — прогон на реальных игровых данных в Termux.

## Реализовано

- [x] Отдельный репозиторий ANOMALY-PDA.
- [x] Game Graph parser: заголовок, уровни, вершины, рёбра и Level Points.
- [x] Чтение embedded Cross Tables после Level Points.
- [x] Проверка byte-offsets, диапазонов и ссылок на Game Graph vertices.
- [x] Level Graph parser для `level.ai` v10/v13.
- [x] Декодирование 4 packed-ссылок соседей, cover, plane и grid position.
- [x] Ленивая расшифровка Level Graph nodes — не создаём объект на каждый из 1.85 млн узлов.
- [x] Проверка соответствия Level Graph ↔ Cross Table по количеству узлов и GUID.
- [x] Локальный A* по Level Graph.
- [x] Межуровневый Dijkstra по Game Graph.
- [x] Сборка составного маршрута из локальных участков и межуровневых переходов.
- [x] Синтетические unit-тесты форматов и локального маршрута.

## Подтверждённые данные Anomaly

- Game Graph: 5 345 вершин, 13 444 ребра, 764 226 Level Points, 34 уровня.
- `fake_start/level.ai`: 14 569 байт = 56 + 631 × 23.
- `zaton/level.ai`: 42 578 829 байт = 56 + 1 851 251 × 23.
- `level.ai` v10 имеет 56-байтовый header и 23 байта на узел; v13 — 25 байт на узел.
- Cross Table имеет 44-байтовый header и 6-байтовые cells; таблицы могут быть встроены в Game Graph.

## Проверка

- Проверены арифметические размеры структур и соответствие размеров двух реальных `level.ai` формату v10.
- Все файлы записаны в GitHub и повторно прочитаны после записи.
- Синтетические тесты подготовлены для Game Graph, Cross Table, Level Graph v10/v13 и A*.

**Не утверждаю, что unit-тесты уже прошли:** полный запуск Python-тестов и прогон парсеров на реальном payload Anomaly ещё не выполнены в Termux. Также ещё не подтверждено, что все 34 Cross Tables совпадают с 34 файлами `level.ai`.
